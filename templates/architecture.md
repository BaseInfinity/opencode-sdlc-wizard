### Example: `2026-05-04` — Use `Bun.spawnSync` not `execFile` in plugin

**Context:** OpenCode 1.14.x runs plugins inside a bundled bun
runtime. `node:child_process.execFile` and Bun's `$` shell API both
hang silently when invoking bash hooks from plugin event handlers
— callback / promise never resolves.

**Options considered:**
- `execFile` async — hangs (rejected)
- Bun `$` async — hangs (rejected)
- `Bun.spawnSync` synchronous — works; blocks event loop briefly

**Decision:** Use `Bun.spawnSync(["bash", hookPath])` synchronously.

**Trade-offs accepted:** Brief event-loop block per hook invocation
(50-500ms). Acceptable for advisory hooks; if performance regresses
materially, revisit.

**Revisit when:** OpenCode upstream fixes the async-hang or ships
a different async-friendly invocation pattern.
